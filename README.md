# NLSG CC downloads

Installers for **NLSG CC** (Next Level Sim Gaming Control Center) by ElHydro, ShenronZero and PSPS. This page is for downloading only; it holds no source code.

## Download

**[Download NLSG CC 1.1.1 Setup](https://github.com/llprankll-rgb/NLSG-CC-Downloads/releases/download/v1.1.1/NLSG-CC-1.1.1-Setup.exe)** (about 1.9 GB)

All versions are on the [Releases page](https://github.com/llprankll-rgb/NLSG-CC-Downloads/releases). You only need the `Setup.exe` file. Ignore the "Source code" links GitHub adds to every release: they contain only this page.

## Install

1. Close your VR games and SteamVR.
2. Run `NLSG-CC-1.1.1-Setup.exe`.
3. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
4. Updating from an earlier NLSG CC? Just install over it; your settings are kept.
5. Want a clean start? Tick **Fresh install** in the installer. Your old settings are moved to a backup folder, not deleted, and other OpenXR toolkits are switched off so they cannot conflict.

Then open **NLSG CC** from the Start menu, pick your game and headset, and press **Review and apply**.

## What you need

- Windows 10 or 11, 64-bit
- A PC VR headset that uses OpenXR (Pimax, Quest via Link or Virtual Desktop, Varjo, Bigscreen, PSVR2 and others)

## Uninstall

Settings > Apps > NLSG CC > Uninstall. Other OpenXR layers that NLSG CC switched off are switched back on.
